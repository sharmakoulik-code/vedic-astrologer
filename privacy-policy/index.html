Privacy policy

This page explains the privacy practices relevant to the VedicAstrologer experience, including how birth details and personal information may be collected or used when using the platform.

Core principle

  • Only collect data necessary for a personalized astrology experience.
  • Protect user information as a matter of responsibility.
  • Do not expose personal data in public-facing content.
  • Use secure hosting and responsible platform practices.

Information collected

Depending on the implementation, the platform may collect personal details such as name, birth date, birth time, and place of birth to generate a personalized reading. These details should be treated as sensitive data and stored only when required by the platform’s actual architecture.

How it is used

This information is used to produce a tailored astrology report and improve the user experience. It should not be publicly displayed in a way that exposes personal or private details beyond the intended report flow.
